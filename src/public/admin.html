Choose a file or drop it here Netscape format, .txt, up to 5 MB

How to export one:

  1. Log in to Instagram in a browser.
  2. Install a “Get cookies.txt” extension (Chrome or Firefox).
  3. Export for instagram.com — the file must start with # Netscape HTTP Cookie File.
  4. Upload it here. Cookies expire after a few weeks, so repeat this when Instagram stops working.
