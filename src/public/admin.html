How do I export one?
  1. Log in to Instagram in your browser.
  2. Install a "Get cookies.txt" extension for Chrome or Firefox.
  3. Export the cookies for instagram.com. The file has to begin with # Netscape HTTP Cookie File.
  4. Upload it here, then run the test below.

Test Instagram
